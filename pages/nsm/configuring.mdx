# Configuring & Setting Up the Application

<Callout type="warning">

This page is towards Divisional Commanders.

</Callout>

While applications Server Configurations are only editable by engineers, you are free to request a configure change.

## Setting up the Bot

Start by filling in the sample config and sending it to khaosen via Discord.

## Permissions

Permission roles are centralized and **may not** be configured. These roles are;
- Sheet Administrator
- Sheet Moderator
- Event Manager

Keep in mind all role names are case sensetive. To see which role may see which commands, check out the commands section.

## Sample Sheet

Bot requires three (3) pages to work. These are:
- 'BACKEND'
- 'BACKEND RECORDS'
- 'EMPLOYMENT RECORDS'

Backend is used to contain active personnel data while Backend Records is used to contain disciplinary action data.
Employment Records are used to contain former employments. (ie. discharged personnel)

<Callout type="warning">

All three of the pages must be in 1/1 match with the linked sample sheet, except qualifications, which may be customized. [Click me for the sample sheet.](https://docs.google.com/spreadsheets/d/15HdG_llgZhpjH6lqVhQDPofIk70Go5jVDTdQ5N06d2o/edit?usp=sharing)

</Callout>

<Callout type="warning">

Second rows of each page must stay as it is. (ie, "dont delete me" written on all columns.)

</Callout>

<Callout type="error">

In NO circumstances you should manually edit any Google Spreadsheet Pages used by the bot. Shall it be required, contact one of our engineers.

</Callout>
