# Configuring & Setting Up the Application

<Callout type="warning">

This page is towards Divisional Commanders.

</Callout>

## Administrative Permissions

Administration roles are centralized and **may not** be configured. These roles are;
- Sheet Administrator
- Sheet Moderator
- Event Manager

However, the general role that allows usage of non-administrative commands are customizable as seen in the sample config below.

Keep in mind all role names are case sensetive. To see which role may see which commands, check out the commands section.

## General Permission

As visible in the Configuring section, general role, the role that allows usage of non-administrative commands is customizable via server config.
