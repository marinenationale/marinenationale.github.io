## Log Channels

There are 4 log channels. These are;
- Event Logs
```
Channel name: "nsm-event-logs"
Channel purpose: Logging of created events.
```
- Lease of Absence Request Logs
```
Channel name: "nsm-loa-logs"
Channel purpose: Logging of leave of absence requests.
```
- Funding Request Logs
```
Channel name: "nsm-fund-logs"
Channel purpose: Logging of fund requests.
```
- Strike Logs
```
Channel name: "nsm-strike-logs"
Channel purpose: Logging of all actions related to strikes.
```

- Qualification Logs
```
Channel name: "nsm-qualification-logs"
Channel purpose: Logging usage of /setqualification command. 
Keep in mind qualification gains from trainings would be logged to Event Logs and not here.
```
