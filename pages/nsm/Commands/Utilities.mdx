---
Utility Commands
---

## /sync

Synchronizes your sheet information with real time data from ROBLOX.

```
/sync
```

## /lookup

See your or someone else's profile. Only Sheet Moderators (or above) may use this command on someone else.

```
/lookup username?
```

**Parameters**
- username?: `ROBLOX Username`

## /version

See application's current version.

```
/version
```
