---
Utility Commands
---

## /sync

Synchronizes your sheet information with real time data from ROBLOX.

```
/sync
```

## /lookup

See your or someone else's profile. Only Sheet Moderators (or Sheet Administrators) may use this command on someone else.

```
/lookup user?
```

**Parameters**
- user?: `Discord User`

## /version

See application's current version.

```
/version
```
