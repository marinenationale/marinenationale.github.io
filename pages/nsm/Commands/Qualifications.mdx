Qualification Commands
---

## /setqualification

Allows you to add/remove the qualification from the given username.

```
/setqualification username qualification status
```

**Parameters**
- username: `ROBLOX Username`
- qualification: `Name of the qualification`
- status: `Active/Not Active`


## /viewqualification

Allows you to view all qualifications.

```
/viewqualification
```
