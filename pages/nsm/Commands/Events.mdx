Event Commands
---

## /event

Allows you to create a fully customized event.

```
/event
```

**Required Permission**
- Event Manager

## /training

Allows you to create one of the pre-configured trainings.

```
/training type time
```

**Parameters**
- type: `Type of the training`
- time: `Time the training will start (UNIX)`

**Required Permission**
- Event Manager

## /viewtrainings

Allows you to view all pre-configured trainings.

```
/viewtrainings
```
