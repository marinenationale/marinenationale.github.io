Employee Management Commands
---

## /addemploye

Opens a Discord Form.

```
/addemploye
```

**Required Permission**
- Sheet Administrator

## /editemployee

Edits variables of the strike linked with the given Strike ID.

```
/editemployee username
```

**Parameters**
- username: `ROBLOX Username`

**Required Permission**
- Sheet Administrator

## /discharge

Moves the row with the given username from main page to the records page, effectively discharging them.

```
/discharge username type
```

**Parameters**
- username: `ROBLOX Username`
- type: `Type of the discharge: Honorable/General/Dishonorable`

**Required Permission**
- Sheet Administrator
